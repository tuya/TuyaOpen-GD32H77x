# DMA SPI AT 长度与地址边界回环

使用正式 `at_spi_transport.c`，配合带 `AT+TY553XLOOP` 的 VW553 SPI 诊断固件。
复用 `spi_at_binary_probe` 的检查，不需要手动复位模块。

```sh
.venv/bin/python platform/GD32H77X/gd32h77x_os/tools/build_project.py \
  platform/GD32H77X/gd32h77x_os/project/spi_at_dma_boundary_probe build \
  --chip GD32H779VW --board GD32H779V_START
```

矩阵共 39 种长度 × 8 种地址偏移 × 4 种二进制模式 = 1248 项：

- 长度：1/2/3/4/5/7/8/9、15/16/17、31/32/33、63/64/65、127/128/129、
  239/240/241、255/256/257、479/480/481、1023/1024/1025、
  2003/2004/2005/2017/2023、4095/4096。
- 发、收缓冲区各以 32 字节对齐存储的起点偏移 0–7 字节，覆盖模 4 和模 8 的所有余数。
- 模式：全零、全 FF、含 NUL/CR/LF/AT 标记的特殊字节、可复现伪随机。
- 每项检查模块返回的序号、长度和 CRC32，逐字节比较回传数据，检查完整结束标记，
  并检查调用者发送/接收缓冲区前后的哨兵没有被修改。

DMA 底层通过独立的 32 字节对齐缓冲区发送固定 256 字节物理帧；
调用者的数据地址及长度不需要按 4/8 字节对齐。长度通过协议头显式携带，
填充字节不能作为用户数据交付。零长度物理帧用于控制/轮询，不是一次非空业务发送。

本探针验收范围为 1–4096 字节分片重组，不代表任意无限长度、吞吐或长稳验收。
运行专用探针会暂时停止 switch_demo；测试后应恢复其 DMA 固件，不擦除 KV 分区。
